# Rotation aléatoire des portraits — v130

- Une nouvelle sélection d'élèves apparaît toutes les 15 secondes.
- Les élèves sont choisis de façon aléatoire.
- Les vraies photos restent prioritaires.
- Les initiales complètent l'affichage quand une photo manque.
- Une transition courte évite un changement brutal.
- Les portraits restent masqués sur petit écran.
- Seuls les élèves autorisés pour l'utilisateur connecté sont utilisés.
