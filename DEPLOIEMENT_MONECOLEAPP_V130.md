# Déploiement MonEcole v130

Utilisez `monecole-v130-mise-a-jour-monecoleapp-20260719.zip` pour mettre à jour le dépôt `monecoleapp`.

Après déploiement :

1. Rechargez complètement l'application.
2. Vérifiez que la version affichée est v130.
3. Ouvrez une rubrique contenant une barre de titre.
4. Attendez 15 secondes et vérifiez que les portraits changent doucement.
